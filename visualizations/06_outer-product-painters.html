What's happening?

Matrix mode: the toy 12×8 matrix is built from 5 latent factors. With k=1 you already capture the dominant pattern; by k=5 the residual is exactly zero. This is the bridge from matrix factorization to truncated SVD: keep the top k outer products by singular value σr and you get the best rank-k approximation.

Image mode: the same trick compresses an image. A few outer products store the broad strokes; later ones add fine detail. This is exactly how SVD-based image compression works.
