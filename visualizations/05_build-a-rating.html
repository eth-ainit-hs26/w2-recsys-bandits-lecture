What's happening?

Matrix A stacks the 2-D user embeddings as rows; matrix B stacks the item embeddings as columns. Multiplying them is just running this animation for every cell — each cell is an inner product, a tiny dot-product story between one user and one item.

Sign tells the story: products of like-signed coordinates push the rating up, opposite signs pull it down. That is why users and items in the same quadrant end up with the largest positive predicted rating.
